# Environment

This machine runs **Arch Linux**.

## Key Paths
- Package management: `pacman` and `yay` are available, also the `chaotic-aur` mirrors are configured
- Services: `systemctl` for systemd units, `journalctl` for logs
- Python: managed via **pyenv** (`~/.pyenv/shims/python`)
- Docker: available (`docker` CLI)
- Also present: `nix`, `rg`, `tldr`, `fd`, `git`, `node`, `npm`, `go`
